Consumable Data via Quantum Communication

A research paper asks whether useful data can be sent as a quantum state, used for a computation, and then become genuinely harder to reuse.

JUL 2026 GOOGLE QUANTUM AI QUANTUM COMMUNICATION
ONE-WAY COMMUNICATION

THE QUESTION

What if data could be useful, but not freely reusable?

Classical information is easy to copy. Once a buyer receives an ordinary data file, the same file can usually support many later computations at almost no extra cost. That makes data economically different from physical inputs such as fuel or raw materials.

This paper studies a narrower, information-theoretic possibility. Alice holds data and sends Bob a quantum message that helps solve a task. If using that message for one task makes it costly to solve many more tasks, the data behaves like a consumable resource.

one useful state ≠ unlimited uses
01

Classical copy

A classical message can be duplicated before it is used, so one delivery can serve many compatible computations.

02

Quantum use

Measuring a quantum state can disturb it. That physical constraint can make reuse expensive for particular tasks.

03

Important caveat

No-cloning alone is not enough. The state must be both useful for the task and hard to reuse in the stated communication model.

THE PAPER'S TEST

How quickly does communication cost grow when the same data must support more tasks?

The authors formalize an asymmetric direct-sum question. Alice keeps one input, while Bob holds m different inputs and wants an answer for every pairing. A problem is called consumable when the communication needed for those m uses grows polynomially relative to a single use.

SINGLE USE c(P) Cost to solve one task
→
MANY USES c(Pm) Cost to solve m related tasks
→
CONSUMABLE mΩ(1) Polynomial growth in the ratio

Why this matters The framework measures the cost of communication from Alice to Bob, not an all-purpose guarantee that quantum data cannot be copied or shared.

THREE EXAMPLES

Where the paper finds quantum data can become consumable.

01

Hidden Matching

Alice's quantum state can reveal one matching-related answer. For multiple hidden matchings, the paper proves a lower bound that grows as Ω(√m) for the stated parameter range.

RESULT: A QUANTUM MESSAGE CANNOT SIMPLY BE REUSED FOR EVERY MATCHING
02

Linear Regression Sampling

For a sampling version of linear regression, the paper shows a setting where quantum communication grows essentially linearly with the number of requested samples, while classical communication can be reused.

RESULT: CONSUMABILITY RATE m FOR THE CONSTRUCTED INPUTS
03

Many observers

When multiple Bobs are limited to single-copy measurements and classical communication between themselves, estimating many observables can require a number of copies that grows nearly linearly with the number of observables.

RESULT: THE COMMUNICATION MODEL CHANGES THE OUTCOME

NOT AUTOMATIC

An exponential quantum advantage does not by itself make data consumable.

The paper also identifies a limit. In some decision problems, a receiver can use shadow tomography to estimate the answers to many two-outcome measurements from a number of copies that grows only polylogarithmically with the number of measurements.

The lesson is subtle: the task, the number of possible outputs, the allowed measurements, and whether recipients can exchange quantum information all affect whether the data is consumable.

SETTING CAN DATA BE REUSED? WHY
Deterministic classical message Yes The receiver can copy the message.
Quantum state, task-specific measurement Sometimes costly Using the state can limit later task-specific use.
Quantum recipients can communicate quantumly Often more reusable Joint procedures can reduce the copies needed.

ECONOMIC INTERPRETATION

The authors connect communication complexity to the economics of data.

Classical data is commonly treated as non-rival: one buyer's use does not stop another use, because copying is cheap. The paper argues that, in specific quantum communication settings, a useful state can instead behave more like a rival input. More uses require more communication.

CLASSICAL DATACopy onceReuse across many tasks
→
QUANTUM DATASend againMore task uses can require more states
→
MARKET EFFECTPrice per useA theoretical path to value that scales with use

This is a theoretical result, not a ready-made data-market product. The paper's conclusions depend on the selected tasks and communication restrictions, and it discusses these constraints explicitly.

QCAASNET TAKEAWAY

Quantum states may make some data uses scarce - but only in carefully defined settings.

01

Consumption is task-dependent

Quantum data is not universally one-time-use. The relevant question is whether it can support many instances of a particular computation.

02

Restrictions matter

Allowing multi-copy measurements or quantum communication between recipients can fundamentally change the resource cost.

03

It links physics and economics

The work uses destructive measurement as a bridge between quantum information theory and the value of data in a market.

THE CORE IDEA A quantum state can be valuable precisely because using it for one computation may limit its value for the next.
